## Folie 4: Der Status Quo – Kleine Unternehmen und ihre Webpräsenz

**Titel:** "Das Problem: 60% der kleinen Unternehmen haben keine zeitgemäße Website"

**Bullet Points:**
- Kleine Unternehmen und Selbstständige können sich teure Agenturen oft nicht leisten
- DIY-Baukästen (Wix, Squarespace) liefern generische Ergebnisse
- Programmierkenntnisse fehlen
- Ergebnis: Veraltete oder gar keine Webpräsenz

**Sprechtext:**
Schauen wir uns das Problem an. Laut einer Studie des Digitalverbands Bitkom haben viele kleine Unternehmen und Selbstständige keine zeitgemäße Website. Der Grund ist meistens nicht fehlendes Interesse, sondern fehlendes Budget und fehlende technische Kenntnisse. Eine Agentur kostet tausende Euro. Die Baukasten-Lösungen wie Wix oder Squarespace liefern zwar schnelle Ergebnisse, aber die sehen oft generisch aus – jede dritte Handwerker-Website sieht gleich aus. Und selbst programmieren? Dafür fehlt die Zeit und das Know-how.

## Folie 7: Die tiefere Herausforderung

**Titel:** "Es geht nicht nur um Code – es geht um Inhalte, Design und Strategie"

**Bullet Points:**
- Eine Website besteht nicht nur aus HTML und CSS
- Texte müssen geschrieben werden (SEO-optimiert, zielgruppengerecht)
- Bilder und Grafiken werden benötigt
- Das Design muss zur Marke passen (Corporate Identity)
- Die Struktur muss den Nutzer führen (UX)
- Rechtliche Anforderungen (Impressum, Datenschutz)

**Sprechtext:**
Aber eine Website ist mehr als nur Code. Es braucht überzeugende Texte, professionelle Bilder, ein stimmiges Design, eine klare Nutzerführung. Normalerweise braucht man dafür einen Texter, einen Designer, einen Fotografen und einen Entwickler. Vier verschiedene Kompetenzen, vier verschiedene Ansprechpartner, vier verschiedene Budgetposten. Das ist die eigentliche Herausforderung: Kann KI alle diese Rollen gleichzeitig unterstützen?

## Folie 8: Was steht auf dem Spiel?

**Titel:** "Die Kosten des Nichtstuns"

**Bullet Points:**
- Verlorene Kunden durch unprofessionellen Webauftritt
- Wettbewerbsnachteil gegenüber Konkurrenten mit modernen Websites
- Vertrauensverlust: "Wenn die Website so aussieht, wie arbeiten die dann?"
- Besonders kritisch in Branchen, die auf Vertrauen basieren (Gutachter, Anwälte, Ärzte)

**Sprechtext:**
Was steht auf dem Spiel, wenn kleine Unternehmen das Problem nicht lösen? Ganz einfach: Kunden. Studien zeigen, dass 75% der Nutzer die Glaubwürdigkeit eines Unternehmens anhand des Website-Designs beurteilen. Für einen Kfz-Gutachter ist Vertrauen das wichtigste Kapital. Wenn jemand nach einem Unfall einen Gutachter sucht, muss die Website Kompetenz und Seriosität ausstrahlen. Eine veraltete Website signalisiert das Gegenteil.

## Folie 13: Herausforderungen und Learnings

**Titel:** "Was nicht sofort funktioniert hat"

**Bullet Points:**
- Bilder konnten nicht direkt von Chat zu Code übertragen werden → manueller Workflow nötig
- Logo musste als SVG nachgebaut werden → Originaldatei einbinden wäre besser
- Dateiendungen (.jpg vs .jpeg) mussten manuell abgeglichen werden
- GitHub-Authentifizierung: Token statt Passwort war anfangs unklar
- KI generiert guten Code, aber Feintuning und Qualitätskontrolle bleiben beim Menschen

**Sprechtext:**
Natürlich lief nicht alles perfekt. Die größte Herausforderung war der Medienbruch: KI-generierte Bilder aus einem Chat können nicht direkt ins Code-Repository übertragen werden – das erfordert manuelle Schritte. Auch die GitHub-Authentifizierung mit Tokens statt Passwörtern war anfangs eine Hürde. Und die KI hat einmal Dateiendungen verwechselt – .jpg statt .jpeg. Das sind genau die Stellen, wo der Mensch als KI-Manager eingreifen muss. Die KI ist ein mächtiges Werkzeug, aber kein Autopilot.

## Folie 15: Ihr konkreter Workflow zum Mitnehmen

**Titel:** "So starten Sie Ihr eigenes Projekt"

**Nummerierte Schritte:**
1. **Briefing erstellen:** Was soll die Website leisten? Wer ist die Zielgruppe?
2. **Bestehende Inhalte sammeln:** Texte, Logos, Kontaktdaten, Bilder
3. **KI-Tool wählen:** Claude, ChatGPT, Cursor, Bolt – je nach Bedarf
4. **Iterativ arbeiten:** Ergebnis prüfen → Feedback geben → verfeinern
5. **Bilder generieren:** DALL-E, Midjourney oder ähnliche Tools für Grafiken
6. **Veröffentlichen:** GitHub Pages, Netlify oder Vercel (kostenlos!)
7. **Qualitätssicherung:** Testen auf verschiedenen Geräten, Inhalte prüfen

**Sprechtext:**
Damit Sie morgen selbst loslegen können, hier der konkrete Workflow. Schritt eins: Erstellen Sie ein klares Briefing. Was soll die Website können? Wer ist die Zielgruppe? Schritt zwei: Sammeln Sie alle bestehenden Inhalte – Texte, Logos, Kontaktdaten. Schritt drei: Wählen Sie Ihr KI-Tool. Ich habe Claude genutzt, aber ChatGPT, Cursor oder Bolt funktionieren ähnlich. Schritt vier, und das ist der wichtigste: Arbeiten Sie iterativ. Prüfen Sie das Ergebnis, geben Sie Feedback, verfeinern Sie. Die KI liefert selten beim ersten Versuch das perfekte Ergebnis. Schritt fünf: Generieren Sie Bilder mit KI-Bildtools. Schritt sechs: Veröffentlichen Sie kostenlos über GitHub Pages. Und Schritt sieben: Testen, testen, testen.
